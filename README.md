# Сайт-презентация Владимира Скворцова

Персональный лендинг системного аналитика и архитектора решений. Стек: **Next.js App Router, React, TypeScript и SCSS Modules**.

## Запуск в VS Code

Откройте папку проекта в VS Code и выполните в терминале:

```bash
npm install
npm run dev
```

Перейдите на [http://localhost:3000](http://localhost:3000). Для остановки сервера нажмите `Ctrl+C` в терминале.

Проверка производственной сборки:

```bash
npm run typecheck
npm run build
npm run start
```

`npm run start` запускается после сборки. Шрифты хранятся локально, подключение к Google Fonts не требуется.

## Структура проекта

- `src/app/` — главная страница, общий макет, метаданные, шрифты и глобальные стили.
- `src/components/layout/` — шапка и подвал.
- `src/components/sections/home/` — отдельные блоки главной страницы. Каждый компонент хранится рядом со своим `*.module.scss`.
- `src/styles/` — общие SCSS-примеси, используемые модулями компонентов.
- `src/data/site.ts` — ссылки на социальные сети и основные сведения.
- `public/assets/` — фото и графика. Первый экран использует фрагмент утверждённого референса `hero-reference.png`.

Содержание разделов находится в соответствующих компонентах. Тексты составлены по предоставленным резюме и предназначены для согласования перед публикацией.
