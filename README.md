# 🧭 Сайт-презентация Владимира Скворцова

Персональный сайт системного аналитика, архитектора решений и эксперта по кибербезопасности: опыт, профессиональная экспертиза, примеры задач и контакты для связи.

**Стек:** Next.js (App Router), React, TypeScript, SCSS Modules.

## 🚀 Запуск и проверка

Требуется Node.js. Откройте проект в VS Code и выполните в терминале:

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Проверка и запуск production-сборки:

```bash
npm run typecheck
npm run build
npm run start
```

`npm run start` запускает production-версию после `npm run build`.

## 🔎 Поисковая оптимизация

Для главной страницы настроены заголовок и описание, канонический адрес, карточка ссылки для социальных сетей и структурированные данные профиля. Карта сайта доступна по адресу `/sitemap.xml`, правила для поисковых роботов — по адресу `/robots.txt`.

По умолчанию основным адресом считается `https://landing-page-presentation-sandy.vercel.app`. При подключении собственного домена задайте переменную окружения `SITE_URL` (например, `https://example.ru`) в настройках размещения и пересоберите сайт: адреса в метаданных, карте сайта и `robots.txt` обновятся вместе. Тексты метаданных находятся в `src/data/seo.ts`, изображение для карточки ссылки — в `public/assets/og-cover.jpg`.

### 🌐 Перенос на VPS и собственный домен

Сайт можно развернуть на VPS REG.RU и привязать к домену REG.RU: SEO-настройки не зависят от провайдера. После выбора домена укажите его публичный HTTPS-адрес в `SITE_URL` **до сборки**. Например, для сервера с Linux:

```bash
npm install
SITE_URL=https://example.ru npm run build
npm run start
```

Замените `example.ru` на фактический основной домен. Указывайте тот вариант с `www` или без него, который будет основным, и настройте остальные варианты домена на перенаправление на него. После смены `SITE_URL` сайт необходимо пересобрать. Привязка DNS, HTTPS и постоянный запуск приложения на сервере настраиваются отдельно при развёртывании.

## 📁 Где что менять

- `src/app/` — главная страница, метаданные, шрифты и глобальные стили (`globals.scss`).
- `src/components/layout/` — шапка и подвал сайта.
- `src/components/sections/home/` — блоки главной страницы; каждый компонент находится рядом со своим `*.module.scss`.
- `src/components/ui/` — общие элементы интерфейса, в том числе векторные иконки.
- `src/styles/` — общие SCSS-примеси для компонентов.
- `src/data/site.ts` — контакты и ссылки на социальные сети; `src/data/resume.ts` — опыт, проекты, навыки, образование и должностные обязанности.
- `public/assets/` — логотип и графика: `logo.svg` используется в шапке, подвале и значке вкладки; `hero-waves.webp`, `architecture.svg` и `hero-portrait.webp` оформляют первый экран.
- `public/icons/` — значки для iPhone, iPad и Android; `src/app/manifest.ts` описывает Android-иконки для добавления сайта на экран устройства.
- `src/app/fonts/` — локальные шрифты IBM Plex Sans и Lora и их лицензии.
- `docs/resume-cybersecurity.md` — профиль по кибербезопасности, составленный по предоставленным документам.

Опыт, проекты, навыки, образование и должностные обязанности редактируются в `src/data/resume.ts`, контакты и ссылки — в `src/data/site.ts`. Остальные тексты находятся в компонентах соответствующих разделов. Подробности обязанностей, должностей и дополнительных программ обучения раскрываются по нажатию.
