# 🧭 Сайт-презентация Владимира Скворцова

Персональный сайт системного аналитика и архитектора решений: опыт, профессиональная экспертиза, примеры задач и контакты для связи.

**Стек:** Next.js (App Router), React, TypeScript, SCSS Modules.

## 🚀 Запуск и проверка

Требуется Node.js. Откройте проект в VS Code и выполните в терминале:

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Проверка и запуск production-сборки:

```bash
npm run typecheck
npm run build
npm run start
```

`npm run start` запускает production-версию после `npm run build`.

## 📁 Где что менять

- `src/app/` — главная страница, метаданные, шрифты и глобальные стили (`globals.scss`).
- `src/components/layout/` — шапка и подвал сайта.
- `src/components/sections/home/` — блоки главной страницы; каждый компонент находится рядом со своим `*.module.scss`.
- `src/styles/` — общие SCSS-примеси для компонентов.
- `src/data/site.ts` — основные сведения и ссылки на социальные сети.
- `public/assets/` — фотографии и графика; `hero-reference.png` содержит фрагмент утверждённого первого экрана.
- `src/app/fonts/` — локальные шрифты Manrope и Lora и их лицензии.

Содержание разделов редактируется в соответствующих компонентах. Ссылки на социальные сети задаются в `src/data/site.ts`.
