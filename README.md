# 🧭 Сайт-презентация Владимира Скворцова

Персональный сайт системного аналитика и архитектора решений: опыт, профессиональная экспертиза, примеры задач и контакты для связи.

**Стек:** Next.js (App Router), React, TypeScript, SCSS Modules.

## 🚀 Запуск и проверка

Требуется Node.js. Откройте проект в VS Code и выполните в терминале:

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Проверка и запуск production-сборки:

```bash
npm run typecheck
npm run build
npm run start
```

`npm run start` запускает production-версию после `npm run build`.

## 📁 Где что менять

- `src/app/` — главная страница, метаданные, шрифты и глобальные стили (`globals.scss`).
- `src/components/layout/` — шапка и подвал сайта.
- `src/components/sections/home/` — блоки главной страницы; каждый компонент находится рядом со своим `*.module.scss`.
- `src/components/ui/` — общие элементы интерфейса, в том числе векторные иконки.
- `src/styles/` — общие SCSS-примеси для компонентов.
- `src/data/site.ts` — контакты и ссылки на социальные сети; `src/data/resume.ts` — опыт, проекты, навыки, образование и должностные обязанности.
- `public/assets/` — фотографии и графика: `hero-waves.png` используется как фон первого экрана, `architecture.svg` — как отдельный слой архитектурной схемы, а `hero-reference.png` и `hero-portrait-mask.png` — для отдельного слоя портрета.
- `src/app/fonts/` — локальные шрифты Manrope и Lora и их лицензии.

Опыт, проекты, навыки, образование и должностные обязанности редактируются в `src/data/resume.ts`, контакты и ссылки — в `src/data/site.ts`. Остальные тексты находятся в компонентах соответствующих разделов. Подробности обязанностей, должностей и дополнительных программ обучения раскрываются по нажатию.

Тексты подготовлены по предоставленным резюме и должностным инструкциям. Инструкции представлены как описание функций и требований должностей, отдельно от результатов проектов. Описания проектов не содержат внутренних технических подробностей.
