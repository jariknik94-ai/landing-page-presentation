# 📋 История изменений

## 🌊 v0.9.2 — ускорение загрузки фона на первом экране

- Фон с волнами переведён на `next/image`. Браузер находит его в исходном HTML, сразу запрашивает с высоким приоритетом и выбирает размер под экран.
- Волны занимают всю ширину блока с сохранением пропорций. На больших экранах они выровнены по нижнему краю, на экранах шириной до 1000 пикселей сохранено прежнее положение.
- В локальной проверке Chrome при размере экрана 375 × 812 и плотности 2× загрузил 11,8 КиБ вместо 171,5 КиБ (на 93% меньше). На шести проверенных размерах экрана фон загружался одним запросом.

## ⚡ v0.9.1 — ускорение загрузки портрета на первом экране

- Портрет первого экрана переведён на `next/image`. Браузер выбирает размер изображения с учётом экрана и загружает его с высоким приоритетом.
- Проверенные локально варианты WebP с прозрачным фоном весят 13–57 КиБ. Исходный файл весит 450 КиБ.

## ✨ v0.9.0 — подготовка домена и автодеплоя

- Добавлены данные о будущем домене `vs-profile.ru`; описана подготовка VPS, DNS и HTTPS.
- Для VPS-сборки настроен `SITE_URL=https://vs-profile.ru`; текущий адрес по умолчанию сохраняется до запуска на новом домене.
- Подготовлен автодеплой через GitHub Actions: проверка форматирования, production-сборка и проверка типов перед развёртыванием коммита по SSH.
- После развёртывания workflow перезапускает службу systemd и проверяет ответ сайта; добавлен пример конфигурации службы.
- Адрес сервера, имя пользователя, SSH-ключ и отпечаток сервера передаются через GitHub Secrets. Автодеплой выключен до настройки VPS и переменной `DEPLOY_ENABLED`.
- Обновлены README и инструкция по подготовке сервера, секретов и включению развёртывания.

## ✨ v0.8.0 — оформление и адаптация разделов

- Исходный код и стили приведены к единому форматированию с отступами в два пробела; добавлены настройки Prettier и команды для форматирования и проверки.
- Улучшена адаптация портрета в разделе опыта для небольших экранов, планшетов и горизонтальной ориентации телефона.
- Исправлено масштабирование портрета в разделе опыта на экранах с соотношением сторон 4:3, включая размер 1376 × 1032.
- Обновлено визуальное оформление разделов: проекты дополнены схемами, контекстом и ролями, экспертиза и навыки получили разное представление, улучшены читаемость и временная шкала опыта.
- Разнообразлено оформление цитат и добавлены единые визуальные переходы между разделами; сохранены утверждённый первый экран и информация из резюме.
- На телефонах портрет расположен перед карьерным путём, а на вертикальных планшетах — рядом с заголовком; список должностей занимает доступную ширину.
- Добавлена отдельная зеркальная копия портрета для раздела опыта; изображение сохраняет размер при раскрытии должностей и не перекрывает фон раздела.
